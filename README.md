# NUCLEO-MAP

Interaktywna przeglądarka wyprowadzeń (pinoutu) dla płytki **STM32 NUCLEO-F746ZG**.

**Link do aplikacji:** [https://nucleomap.netlify.app/](https://nucleomap.netlify.app/)

## Funkcje
* Szybkie wyszukiwanie pinów po nazwie.
* Obsługa wyszukiwania dokładnego (w cudzysłowie, np. `"PA4"`).
* Wizualizacja złącz Arduino i Morpho.
* Responsywny interfejs przystosowany do urządzeń mobilnych.

## Technologie
* Next.js, TypeScript, Tailwind CSS, Lottie.
